Caso voce esteja no windows, tenha o gcc e cmake instalados :)

Primeiro crie um diretorio build:

- mkdir build && cd build

logo apos, compile:

- cmake ..

por ultimo crie o executavel:

- cmake --build . --config Release

O executavel ta dentro de Release



no vs code pode fazer isso(dentro de build):

cmake -G "MinGW Makefiles" ..
